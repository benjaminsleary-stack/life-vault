Life-Vault — Privacy

Last updated 25 August 2026

Life-Vault is a personal, single-user application. It is not a product, it has no customers, and it is used by one person: its owner. This page exists because Google requires a privacy policy URL before an OAuth app can be published, and because the honest description below is short.

Who operates it

One individual, for their own use. There is no company, no team, and no other user. Questions: benjaminsleary@gmail.com.

What it stores

Personal notes, tasks, calendar entries and daily briefings, kept as plain markdown files in a private GitHub repository owned by the operator. Nothing is stored in any third-party database or analytics service.

What Google data it uses, and why

  • Google Calendar (calendar.events) — creates events on the operator's own calendar, so a monthly shortlist of family days out appears in the calendar rather than only in a note. This is the narrowest scope that can create an event; it cannot delete a calendar.
  • Calendar subscriptions — read-only private .ics feeds, used to list what is on today.
  • Gmail — read via IMAP with an app-specific password, to summarise which messages need a reply. Message content is read at run time and not retained beyond the run.

Google user data is used only to provide these features to the operator. It is never sold, never shared with third parties, never used for advertising, and never used to train any model.

Where it goes

Data moves between the operator's own GitHub repository, a Cloudflare Worker they control, and their own devices. Briefings are delivered by Web Push, encrypted end to end (RFC 8291) so the push service cannot read them. There are no third-party recipients.

Retention and deletion

Notes are retained until the operator deletes them; the repository is theirs and can be deleted at any time. Google access can be revoked at any time from Google Account → Third-party access, which immediately and permanently ends this app's access.

Security

The repository is private. Credentials are held as encrypted secrets in GitHub Actions and Cloudflare, never in the repository. The application is reachable only with a token held on the operator's own devices.

Children

The application is not directed at children and has no users other than its operator.

Changes

Any change is published on this page with a new date at the top.
